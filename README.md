# Snake Game 🐍

A classic Snake game built in Python using the built-in `turtle` module.

## Features

* Control the snake using **WASD**
* Snake grows when it eats food
* Score increases with each food collected
* Game ends when the snake hits the wall or itself

## Project Structure

```text
main.py          - Runs the game
Snake.py         - Snake movement and behavior
food.py          - Food generation
scoreboard.py    - Score and game-over display
.gitignore       - Files ignored by Git
```

## Concepts Practiced

* Object-Oriented Programming (OOP)
* Classes and objects
* Inheritance
* Modules and imports
* Event listeners and keyboard input
* Turtle graphics
* Collision detection
* File handling
* Python lists

## How to Run

Make sure Python is installed, then run:

```bash
python main.py
```

Use the **WASD** keys to control the snake.
